Field note · from production

Why Windows LAPS only showed the default admin on some new devices (GitHub, opens in a new tab)

Intune reported the LAPS policy as succeeded, yet a few brand-new devices never created the managed account. An Autopatch report gave it away: they had shipped on Windows 11 21H2, and automatic account management needs 24H2 or later.
